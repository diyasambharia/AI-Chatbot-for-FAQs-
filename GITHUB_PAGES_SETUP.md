# 🚀 How to Enable the Live Link on GitHub Pages (60 Seconds)

Your application is designed to run directly on **GitHub Pages** with zero build steps or server setup.

---

### Step 1: Push the Updated Code to GitHub

Open PowerShell or Git Bash in this project directory and run:

```bash
git add .
git commit -m "feat: upgrade FAQ chatbot with clean RAG engine, UI, and live demo"
git push origin main
```

---

### Step 2: Enable GitHub Pages in Repository Settings

1. Open your repository in your browser:
   👉 **https://github.com/diyasambharia/AI-Chatbot-for-FAQs-**

2. Click on the **Settings** tab (gear icon at top right of the repo).

3. In the left sidebar under the **Code and automation** section, click **Pages**.

4. Under **Build and deployment**:
   - **Source**: Select `Deploy from a branch`
   - **Branch**: Choose `main`
   - **Folder**: Choose `/ (root)`
   - Click the **Save** button.

---

### Step 3: Access Your Live Web App!

Within 30 to 60 seconds, GitHub will automatically publish your app at:

🌐 **https://diyasambharia.github.io/AI-Chatbot-for-FAQs-/**

You can share this live link on your resume, LinkedIn, portfolio, or project submissions!
